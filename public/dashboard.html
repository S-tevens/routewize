Connect your app
Connect once. Your app sends requests through Routewise automatically.
OpenAI SDK compatible · Text chat

    

      
1. Set your address and key
Keep your OpenAI SDK. Use this base URL and set ROUTEWISE_API_KEY in your app's server environment.
Your Routewise key authenticates your app. Your OpenAI or Anthropic key must be configured on the Routewise server before model calls can run. Provider charges use those keys.
2. Choose how to route
routewise/auto applies your configured routing rules. An explicit model stays on that model. Matching repeat requests can use response caching when enabled.
3. Read the answer as usual
Read choices[0].message.content. Extra savings details appear in rw_meta, and requests appear in Usage & savings.
Changing the address alone doesn't compress conversation history. Add reference context below when you want to reduce input tokens.

      
Make your first request
Connect your key to list configured models.
Run this in your application backend. This example makes a paid model call when valid provider keys are configured.
Supports non-streaming text Chat Completions, temperature, and max_tokens. Tools, images, structured output, and the Responses API are not supported yet. Unsupported options return an error.

    

    
Optional: send fewer context tokens
Add rw_optimization to the request body with your reference documents. In Python, pass it through extra_body={"rw_optimization": {...}}. Your regular messages remain intact.
{"rw_optimization": {
  "compression": true,
  "selection": true,
  "max_context_tokens": 2000,
  "context": [
    {"id": "refunds", "text": "Refunds are available within 30 days."}
  ]
}}
Use Playground to preview changes without model charges. Use Savings proof to compare paid answers and costs.
