How it works

Semantic cache

Every prompt is embedded and checked against recent similar requests. A close-enough match returns instantly — no API call, no cost, no risk. Pure upside: a cache hit never changes your output quality.

Rules-based router

On a cache miss, your own rules decide what's safe to send to a cheaper model — short, simple, or templated requests only. Anything unmatched falls through to your flagship model, untouched.

What stays in your control

  • You keep your own OpenAI/Anthropic keys — we never see or bill your inference spend.
  • You write the routing rules; we don't guess at quality, we just execute what you configure.
  • Any single request can force full flagship quality with one header, no code change.

Point your API calls at our proxy instead of OpenAI/Anthropic directly. We'll cache repeat requests and route the simple ones to cheaper models based on rules you control. No code changes beyond the base URL.
